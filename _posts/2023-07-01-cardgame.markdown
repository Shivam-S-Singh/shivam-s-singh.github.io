## Overview
I wanted to backup the game data from my MicroSD card on my 3DS to my PC. The 3DS has a file transfer application called _microSD_ _Management_ which lets you access and transfer your files from a Windows 7 or 8.1 PC with Network Sharing enabled. Unfortunately there was some challenges with the application.

## Troubleshooting
### Is it an application issue ?
When I attempted to use the application I found that my PC was not detecting the 3DS in Network Sharing on Windows. I immediately assumed it may have been a compatibility issue since I was on Windows 10 but I continued with my troubleshooting ignoring that fact.

My second theory was that perhaps the protocol being used was maybe being blocked or unsupported by my operating system. 

A quick search for the protocol used by the microSD Management application indicated SMBv1 which is disabled by default on Windows 10. SMBv1 was installed in Windows Features and then allowed through Windows Firewall.
